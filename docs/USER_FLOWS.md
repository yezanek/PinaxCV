# PinaxCV User Flows

## Core flow

Library → Create/Open CV → Edit → Live Preview → Export PDF or HTML

## Variant flow

Base CV → Create Variant → tailor manually/with AI → review suggestions → resolve variant → preview/export.

## HTML website flow

CV → Export → HTML → choose filename → receive one `.html` file → upload to personal website.

The generated HTML must work when opened locally without network access.
