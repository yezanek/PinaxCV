# PinaxCV User Flows

## Core flow

Library → Create/Open CV → Edit → Live Preview → Export PDF or HTML

## Variant flow

Base CV → Create Variant → tailor manually/with AI → review suggestions → resolve variant → preview/export.

## Import flow

CV list → Import… → choose a file (Europass PDF or XML, any text PDF, JSON Resume, LinkedIn ZIP) → preview with warnings → new CV, or merge into an existing CV with per-field and per-entry choices → saved after a snapshot.

Text import: CV list → Import text… → paste or choose a file → see exactly what would be sent → Read with AI (or Read without AI) → same preview and merge.

## AI tailoring flow

Settings → choose provider, model and key → consent for that host → Variants tab → job title, company and description → Analyze and tailor (progress, cancel) → review suggestions (accept, edit then accept, reject, bulk actions) and gap questions → preview/export.

## Data flow

Settings → Your data → Back up… / Restore from backup… / Clear AI cache / Delete all data… (each destructive step asks first).

## HTML website flow

CV → Export → HTML → choose filename → receive one `.html` file → upload to personal website.

The generated HTML must work when opened locally without network access.
