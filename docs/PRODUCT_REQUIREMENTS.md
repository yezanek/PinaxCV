# PinaxCV Product Requirements Summary

## V1

PinaxCV is a local-first CV builder for Linux and Windows. It uses SQLite, exports ATS-compatible PDF and standalone HTML, imports common CV formats, supports job-specific variants, and provides optional consent-gated AI assistance.

## Later if justified

- macOS desktop
- hosted SaaS with PostgreSQL
- accounts/authentication
- synchronization
- hosted backups
- subscriptions/billing

The future features are not prerequisites for the initial product.
